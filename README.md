### Student Management System (Full-Stack JavaScript)

A modern, full-stack web application designed for educational institutions to efficiently manage, filter, and analyze student enrollment data. This project is built entirely using the JavaScript ecosystem, utilizing a Node.js/Express backend, a dynamic frontend, and MongoDB for flexible data storage. 

### 🚀 Tech Stack

* **Frontend:** HTML5, CSS3 / Tailwind CSS (Custom Dark Theme), JavaScript (ES6+)
* **Backend:** Node.js, Express.js (RESTful API architecture)
* **Database:** MongoDB (NoSQL) with Mongoose ODM

### 🌟 Key Features

### 1. Student Registration & Enrollment

* **Intuitive Sidebar Form:** A dedicated input panel to quickly add new student records.
* **Comprehensive Data Fields:** Captures essential student details including Student ID, First Name, Last Name, Email, Course, Batch, and Age.

### 2. Live Analytics & Insights Dashboard

* **KPI Metrics:** Top-level metric counters showing real-time aggregates for Total Students, Course Categories, and Top Course Counts.
* **Course Distribution Analytics:** Visual progress/bar charts tracking enrollment densities across various subjects (e.g., Cyber Security, Computer Science, Data Science).

### 3. Advanced Data Filtering & Sorting

* **Instant Search Functionality:** A global search bar allowing administrators to filter records instantly by typing partial keywords (e.g., names or courses).
* **Dynamic Sorting:** Dropdown configuration to sort data tables dynamically by Student ID, name, or other parameters.

### 4. Interactive Record Management (CRUD)

* **Structured Data Grid:** A clean, centralized table showcasing active student directories with clear typography.
* **Inline Action Handlers:** Dedicated, color-coded interactive buttons (**Edit** and **Delete**) built into every row for quick database updates.
